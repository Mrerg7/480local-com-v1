# Changelog — 480Local.com

## [FEAT]: Comprehensive optimization — 2026-10-03

Stays on **Cloudflare Workers free plan** (static assets + edge `src/worker.ts`, no paid bindings, no server DB).

### I. Technical foundation
- `astro.config.mjs`: `compressHTML`, `inlineStylesheets:auto`, Vite `cssMinify/minify`, sitemap `changefreq/priority/lastmod`, viewport prefetch.
- `public/_headers`: HSTS, nosniff, `X-Frame-Options:DENY`, `Referrer-Policy`, `Permissions-Policy`, CSP (self + fonts + imagedelivery + CF beacon), `Cross-Origin-Opener-Policy`, immutable cache for `/_astro/*`, `must-revalidate` for HTML. Kept `X-Robots-Tag:noindex` for `/index.html` duplicates.
- `public/robots.txt`: allow `/`, sitemap points to `sitemap-index.xml` (generated by `@astrojs/sitemap`).
- `public/manifest.webmanifest`: installable PWA metadata, theme colors.
- `src/worker.ts`: unchanged — www→apex 301 before asset lookup (canonical consolidation), `run_worker_first=true` in `wrangler.toml`.
- Canonical: single `https://480local.com/` via `Layout` + `SEO` OG/Twitter URLs; `_redirects` collapses `/index.html`, `/home`, `/index`, `/search` duplicates.
